# オールインワン個人執筆スタジオ (Personal Writing Studio)

完全個人利用専用の、執筆におけるすべてを1画面で完結させるモダンな執筆Webアプリケーションです。

## 主な機能
- **メモ機能**: 登場人物・世界観・伏線アイテムのカード管理
- **プロット作成**: 起承転結（4幕構成）のアウトライナー
- **本文エディタ**: ルビ記法（`｜漢字《かんじ》`）、傍点（`《《強調》》`）、ダッシュ・三点リーダーワンクリック挿入
- **文庫本風縦書きプレビュー**: リアルタイム反映、縦書き（右から左へスクロール）/ 横書き切替
- **相談用AIアシスタント**: Gemini API連動。作品のプロットや設定メモのコンテキストを自動理解して壁打ち
- **作品ライブラリ**: 複数の物語を独立して作成・管理・切り替え
- **スマホ・タブレット完全対応**: 画面下部のボトムナビゲーションで快適執筆
- **完全ローカル保存**: 原稿データは外部サーバーに送信されず、お使いのブラウザ内に安全に保存
